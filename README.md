# Censo de Población INEGI Coahuila

Proyecto académico desarrollado bajo arquitectura MVC y Programación Orientada a Objetos.

## Tecnologías

- java
- MySQL
- CustomTkinter
- GitHub

## Base de Datos

Ejecutar:

database/censo_inegi.sql

## Funcionalidades

- Login de administradores
- Registro de viviendas
- Registro de habitantes
- Gestión de municipios y localidades
- Actividades económicas
- Reportes estadísticos
- Dashboard poblacional
